📚 How the Simulation Works

This simulator advances the rocket through small time steps. At every step it calculates atmospheric conditions, thrust, gravity, aerodynamic drag, acceleration, velocity and position.

1️⃣ Engine Thrust

T = ṁVₑ + (pₑ − pₐ)Aₑ

Exhaust velocity is calculated from Vₑ = Isp × g₀. The pressure term accounts for nozzle exit pressure and changing atmospheric pressure.

2️⃣ Gravity

g(h) = g₀ × (Rₑ / (Rₑ + h))²

3️⃣ Atmospheric Density

The model calculates temperature, pressure, density and speed of sound using a simplified piecewise atmosphere.

ρ = P / (RT)

4️⃣ Atmospheric Drag

D = ½ρv²CᴅA

The drag vector is opposite to the velocity vector.

5️⃣ Launch Angle and Force Components

The angle is measured from the ground: 0° horizontal, 45° above horizontal and 90° vertical.

Tₓ = T cos(θ), Tᵧ = T sin(θ)

6️⃣ Net Force

Fₓ = Tₓ + Dₓ

Fᵧ = Tᵧ + Dᵧ − mg

7️⃣ Acceleration

aₓ = Fₓ/m, aᵧ = Fᵧ/m

8️⃣ Velocity Update

vₓ,new = vₓ,old + aₓΔt

vᵧ,new = vᵧ,old + aᵧΔt

9️⃣ Position / Altitude Update

xnew = xold + vₓΔt

hnew = hold + vᵧΔt

🔟 Orbital Velocity

vₒᵣᵦ = √(μ/(Rₑ+h))

This is the ideal circular orbital speed at the selected altitude.

🔄 Complete Simulation Loop

Atmosphere → gravity → thrust → velocity → drag → force components → acceleration → velocity update → position update → Mach/dynamic pressure/orbital velocity → store results → repeat.
